# AI HAIKUS — Complete Website Specification for Cursor
**aihaikus.com** | Created by @888mooncat | February 11, 2023

---

## Project Overview

A permanent archive website for the AI Haikus Ordinal collection — 50 haikus generated by early ChatGPT and inscribed on the Bitcoin blockchain in February 2023. The site functions as a museum catalogue, not a marketplace. Tone: quiet authority, maximum documentation, zero salesmanship.

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS + custom CSS variables
- **Deployment**: Vercel
- **Fonts**: Google Fonts (specified below)
- **No external dependencies beyond what's listed**

---

## Aesthetic Direction

**Concept**: "Ancient Future" — the collision of the oldest poetic form (haiku, feudal Japan) with the newest technology (AI + Bitcoin blockchain). The design should feel like a museum that exists outside of time. Not crypto-flashy. Not web3 garish. Monumental, still, authoritative.

**Color Palette** (CSS variables):
```css
:root {
  --bg: #0a0a08;              /* near-black with warm undertone */
  --bg-elevated: #111110;     /* card backgrounds */
  --gold: #c9a84c;            /* aged gold — primary accent */
  --gold-dim: #7a6330;        /* muted gold for secondary elements */
  --text-primary: #e8e4d9;    /* warm off-white */
  --text-secondary: #8a8478;  /* muted warm grey */
  --text-dim: #4a4840;        /* very dim, for labels */
  --bitcoin: #f7931a;         /* Bitcoin orange — used sparingly */
  --border: #1e1e1a;          /* subtle borders */
  --border-gold: #3a3020;     /* golden-tinted border */
}
```

**Typography**:
- Display / Headers: `Cormorant Garamond` (weight 300, 400, 600) — elegant, ancient, literary
- Body / UI: `DM Mono` (weight 300, 400) — technical, clean, honest
- Haiku text: `Cormorant Garamond` italic, large — the poems deserve reverence
- Load both from Google Fonts

**Visual Details**:
- Subtle grain texture overlay on entire page (CSS noise)
- Very faint horizontal lines as background texture (like aged paper)
- Gold accent lines, not borders — single pixel, precise
- No gradients except very subtle radial glow behind hero text
- Cards have no border-radius — sharp corners, monumental feel
- Hover states: gold color transition, 300ms ease

```css
  opacity: 0;
}

/* stagger via inline style: animation-delay: ${index * 0.03}s */
```
